# Projet Centre Horizon carrousel

Répartition des missions:

* Soren: Javascript
* Ariane: CSS
* Melkior: HTML

Fonctionnalités : 

Cette page du site Centre Horizon permet de visualiser un diaporama d'images grâce à 4 boutons. 
Il s'agit des quatres boutons suivants : 

* slider-previous : afficher la photo précédente.
* slider-toggle : démarrer ou arrêter le carrousel.
* slider-next : afficher la photo suivante.
* slider-random : afficher une photo aléatoire

Ces boutons peuvent être cachés en appuyant sur le bouton "Appuyer/Cacher" en haut à gauche de la page.

Les images peuvent défiler en diaporama dans un ordre précis ou aléatoirement grâce au quatrième bouton.
